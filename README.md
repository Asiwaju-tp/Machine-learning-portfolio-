# Machine-learning-portfolio-
A collection of end-to-end machine learning projects covering classification, regression, computer vision, and anomaly detection built with Python, TensorFlow, and scikit-learn. Includes data preprocessing, model training/evaluation, and results for real-world problems in healthcare, pricing, computer vision, and industrial monitoring.

This repository showcases a set of applied machine learning projects spanning multiple problem types binary classification, regression, image classification, and anomaly detection - each built end-to-end from raw data to a trained, evaluated model. Work was carried out in Python using TensorFlow and scikit-learn within Jupyter Notebook/Miniconda environments, covering the full ML workflow: data cleaning and preprocessing, feature engineering, model selection and training, hyperparameter tuning, and performance evaluation. The projects draw from diverse domains — healthcare risk prediction, pricing/valuation modelling, computer vision for traffic sign recognition, and predictive maintenance for industrial equipment reflecting a broad, practical grounding in how machine learning is applied across different real-world contexts.

Heart-disease-detection/ — Classification model to predict heart disease risk from patient data.
Bulldozer-price-prediction/ — Regression model predicting used bulldozer auction prices.
Traffic-sign-detection/ — Image classification model for recognizing traffic signs.
Bucket-elevator-anomaly-detection/ — Anomaly detection model for industrial bucket elevator monitoring
